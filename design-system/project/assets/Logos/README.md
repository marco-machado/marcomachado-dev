# Logos

`mm-mark.svg` is the `mm` monogram, copied from `public/favicon.svg`. It is a 32×32 tile with a 4px corner radius in teal `#0d7377`, with lowercase "mm" in a 600-weight system monospace in off-white `#faf9f7`.

- It is the favicon and the centre of the Social Image. In the page header the brand is the `wordmark` text style ("Marco Machado"), not this mark.
- The tile colours are fixed hex values, close to but not the same as the `primary` token. Use the mark as is on either theme. Don't recolour it, outline it or put it on a teal ground.
- The letters are live text in a generic `monospace` font, so they can render slightly differently between platforms.
