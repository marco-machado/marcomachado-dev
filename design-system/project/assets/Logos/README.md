# Logos

`prompt-mark.svg` is the brand mark, copied from `public/favicon.svg`: a green `>_` prompt on a near-black tile.

- A 32×32 tile with a 6px corner radius, filled #080c0b (`background`) with a 1px #262d2a (`border`) edge. On it sit a `>` chevron, drawn as a 3px square-capped stroke, and an `_` bar beside its foot, both #6cd79d (`primary`).
- It is all shapes and no text, so it renders the same everywhere. The hex values are the tokens' sRGB values, written as hex so the file works outside the site.
- It is the favicon: `favicon.svg`, and `favicon.ico`, which `scripts/brand-assets.mjs` renders from it. The page header uses the Brand, the domain set in text, not this mark.
- Use it as is. Don't recolour it, outline it or place it on a `primary` ground.
