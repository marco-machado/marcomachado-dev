# Images

`og-default.png` (1200×630) is the site-wide Social Image, copied from `public/images/og-default.png`. It shows a large rounded `mm` monogram tile centred on the dark graphite ground, with `marcomachado.dev` set in widely letter-spaced grey mono underneath.

- An Article without its own `ogImage` uses this one when it is shared.
- New Social Images should follow the same pattern: dark ground, the teal tile, mono lowercase text, nothing else.
